## 3 команды
`ros2 pkg prefix turtlesim` - показывает путь, по которому существует переданный модуль(пакет?)

`n>&k` - направить данные из потока 'n' в поток 'k'
Пример: 2>&1 - направить ошибки (stderr) туда же куда обычный вывод (stdout).

`tee` - показать переданный результат слева, и сохранить в файл.

## Отличие > and |
`>` - перенапрвляет результат выводы левой команды в файл указанный справа (создает файл)
`|` - передает вывод предыдущей команды в следующую


## launch
суть понятна. launch файл - удобный способ набора фоновых процессов (параллельный запуск), где каждый процесс может быть определенной нодой.
Запуск launch запускает ноды, прерывание терминала с запуском, прерывает все ноды запущенные через launch
